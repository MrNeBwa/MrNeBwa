### 🚀 Избранные проекты

* **XENOCIDE (C++ / OpenGL)**
  2D-игра, написанная на C++. Реализован собственный рендеринг через OpenGL, математика движения игрока, обработка матричных преобразований и эффект дрожания камеры (camera shake).
  
* **CMYK to RGB Converter (Python)**
  Скрипт на базе NumPy, который конвертирует цветовые пространства исключительно с помощью чистых математических операций и матричных вычислений, без использования тяжелых deep-learning библиотек.
